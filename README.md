# Smart assisstive coffee scale
A smart coffee scale with assisstive brewing features, aimed to help both occasional and coffee enthusiasts keep track of different recipes and help them brew better coffee in a more consistent and repeatable manner.

## Technologies
- C/C++
- Arduino framework
- ESP32
- HX711 ADC library
- EEPROM
- TFT display library

## Features
- Calibration mode, interactive calibration program saving calibration value to EEPROM.
- Automatically load calibration value from EEPROM.
- Retractable/detractable main unit from scale body.
- Made from ABS plastic, withstanding high-heat without warping.
- Auto-start timer when starting pouring.
- Auto-turn off after 5 min. of inactivity.
- Display shows elapsed time, brewing instructions and flow rate in g/s.
- USB-C rechargeable li-ion battery, 25 hours active on-time.
- Recipes:
  - James Hoffman V60 recipe V2

## Building the project
### Bill of Materials
- 2x screws
- 1x HX711 ADC
- 1x ESP32 MCU
- 1x TP4056 USB-C lithium battery charger module
- 1x 320x240px TFT LCD display
- 0.5kg ABS filament

### Build steps
1) Clone the repository.
2) Open the repository in VS Code.
3) Install the PlatformIO extension to manage and auto-install dependencies.
4) Flash the firmware onto an ESP32.
5) 3D print the scale body and display housing.
6) Install components.
